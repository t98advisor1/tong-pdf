# 통PDF (TongPDF)

디지털 교무수첩(`t-ong.vercel.app`)과 연동되는 독립 PDF 올인원 변환기입니다.

## 구성
1. **웹 변환기 (GitHub Pages)**: 설치 없이 100% 브라우저 내부 처리 (외부 서버 전송 없음)
   - 문서 → PDF 일괄 변환 (`.hwpx`, `.hwp`, `.pptx`, `.docx`, `.txt`, `.md`, `.show` 제한 지원)
   - 이미지(JPG/PNG/WebP) ↔ PDF 변환
   - PDF 합치기 · 페이지 나누기/추출
2. **Windows PC용 무설치 완벽 변환기 (`TongPDF-PC.exe`)**:
   - PC에 설치된 한컴오피스(한글·한쇼)와 파워포인트 COM 자동화를 사용하여 `.hwp`, `.hwpx`, `.show`, `.ppt`, `.pptx`, `.doc`, `.docx`, 이미지를 **원본 레이아웃 100% 그대로** 일괄 PDF 변환합니다.
   - GitHub Releases에서 단일 실행 파일(`.exe`)로 다운로드할 수 있습니다.
