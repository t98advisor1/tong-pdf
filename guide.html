2. 스크린샷으로 따라 하는 단계별 사용설명서

모든 화면은 1단 풀스크린으로 배치했으며, 강조 박스 · 화살표 · 번호를 따라 확인하시면 누구나 1분 만에 사용하실 수 있습니다.

화면 1. 문서 → PDF 일괄 변환 (기본 화면 · Alt+1)

원본 크게 보기 ↗
  • 1PC용 무설치 완벽 변환기 배너: 한쇼(.show)나 복잡한 공문서 한글 파일은 이 파란 배너의 [TongPDF-PC.exe 다운로드] 버튼을 눌러 PC에서 바로 변환하세요.
  • 2파일 드래그 영역: .hwpx, .hwp, .pptx, .docx, .txt, .md 파일을 여러 개 동시에 끌어다 놓거나 클릭해서 선택합니다.
  • 3옵션 및 일괄 변환 바: 용지 방향(자동: 문서는 A4 세로, PPT는 16:9 가로)과 글자 크기를 고른 뒤 [⚡ 전체 PDF 변환] → [📦 전체 ZIP 다운로드]를 누르면 끝납니다.

화면 2. 이미지(JPG/PNG/WebP) ↔ PDF 양방향 변환 (Alt+2)

원본 크게 보기 ↗
  • 1왼쪽 카드 (이미지 여러 장 → PDF 1개): 학습지 사진이나 스캔 이미지를 여러 장 올린 뒤 ▲▼ 버튼으로 순서를 맞추고 A4 맞춤 또는 원본 크기로 PDF를 생성합니다.
  • 2오른쪽 카드 (PDF → 고화질 PNG): PDF 파일 1개를 올리고 해상도(보통/고화질/초고화질)를 선택하면 모든 페이지가 고화질 PNG 이미지 ZIP으로 저장됩니다.

화면 3. PDF 합치기 · 페이지 나누기 / 추출 (Alt+3)

원본 크게 보기 ↗
  • 1왼쪽 카드 (PDF 합치기): 여러 공문서·시험지 PDF를 2개 이상 올리고 ▲▼ 버튼으로 순서를 정한 뒤 [PDF 합쳐서 다운로드]를 클릭합니다.
  • 2오른쪽 카드 (PDF 나누기): 1-3, 5, 8-10처럼 원하는 페이지 범위만 뽑아 새 PDF로 저장하거나, [1페이지씩 ZIP 분리]로 낱장 분리할 수 있습니다.

화면 4. 교무실 Windows PC용 무설치 완벽 변환기 안내 (Alt+4)

원본 크게 보기 ↗
  • 1무설치 실행파일 다운로드: TongPDF-PC.exe 단일 파일을 내려받아 바탕화면이나 USB에 보관합니다.
  • 23단계 사용법: 다운로드 → 더블클릭(첫 실행 시 Windows PC 보호 창에서 추가 정보 → 실행) → 파일 또는 폴더를 창에 통째로 드래그합니다.
  • 3웹 vs PC용 비교표: 어떤 파일은 웹에서 바로 하고, 어떤 파일(한쇼·구형 PPT·복잡한 한글)은 PC용 .exe를 쓰면 좋은지 한눈에 비교할 수 있습니다.

3. 작업 속도를 2배 높여 주는 단축키 모음

통PDF 웹 화면에서 마우스 이동 없이 키보드만으로 탭 이동, 파일 선택, 일괄 변환, ZIP 저장까지 바로 실행할 수 있습니다.

단축키 기능 상세 설명
Alt + 1 문서 → PDF 탭 이동 한글(.hwpx/.hwp)·PPT(.pptx)·워드(.docx) 일괄 변환 화면으로 즉시 이동합니다.
Alt + 2 이미지 ↔ PDF 탭 이동 이미지 합치기 및 PDF → PNG 추출 화면으로 이동합니다.
Alt + 3 PDF 합치기·나누기 탭 PDF 병합 및 페이지 범위 추출 화면으로 이동합니다.
Alt + 4 PC용 무설치(.exe) 안내 교무실 Windows PC용 100% 원본 변환기 다운로드 및 안내 탭으로 이동합니다.
Ctrl + O 파일 선택 창 열기 현재 보고 있는 탭에 맞는 파일 선택 창을 바로 띄웁니다. (Mac은 Cmd+O)
Ctrl + Enter 일괄 PDF 변환 실행 목록에 올려둔 파일들의 PDF 변환(또는 이미지·PDF 병합)을 즉시 시작합니다.
Ctrl + Shift + D 전체 ZIP 일괄 다운로드 변환이 완료된 모든 PDF 파일을 하나의 ZIP 파일로 한 번에 내려받습니다.
F1 사용설명서 새 창 열기 현재 보고 계신 스크린샷·GIF·단축키 공식 사용설명서를 바로 엽니다.
